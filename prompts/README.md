## 整理说明

- 每条独立提示词对应一篇 Markdown 文档，文件名使用英文小写与连字符。
- 图片转录文档保留原文与来源链接；两张城市提示词图片按顺序合并为一篇。
- 原始图片保留在本目录，便于核对。提示词正文中的占位符按实际输入替换。
