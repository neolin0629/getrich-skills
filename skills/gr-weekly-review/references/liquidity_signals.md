# 流动性信号灯判定逻辑

def _calc_signal(ld) -> dict:

    0 = 绿宽松 (宽松/扩张)

## Tier 1 全球流动性

**判定依据**: EFFR（联邦基金利率）趋势

| 条件 | 信号 | 说明 |
|------|------|------|
| EFFR较30日前升>2% | 🔴 红 | 加息周期，收紧 |
| EFFR较30日前降>2% | 🟢 绿 | 降息周期，宽松 |
| 其他 | 🟡 黄 | 按兵不动，中性 |

## Tier 2 中国宏观流动性

**判定依据**: M2货币供应同比

| 条件 | 信号 | 说明 |
|------|------|------|
| M2同比 > 12% | 🟢 绿 | 货币宽松 |
| M2同比 < 9% | 🔴 红 | 货币收紧 |
| 其他 | 🟡 黄 | 稳健中性 |

## Tier 3 A股微观流动性

**判定依据**: 融资余额趋势

| 条件 | 信号 | 说明 |
|------|------|------|
| 融资余额较20日前升>5% | 🟢 绿 | 杠杆入场，扩张 |
| 融资余额较20日前降>5% | 🔴 红 | 去杠杆，收缩 |
| 其他 | 🟡 黄 | 平稳 |

## 综合判定

| 得分 | 综合信号 |
|------|----------|
| 0-1分 | 🟢 整体宽松 |
| 2-4分 | 🟡 整体中性 |
| 5-6分 | 🔴 整体收紧 |

得分规则：
- 🟢 = 0分
- 🟡 = 1分
- 🔴 = 2分
- 综合 = t1 + t2 + t3
