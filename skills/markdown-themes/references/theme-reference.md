# Markdown Themes 主题参考

每次把 Markdown 转 HTML 前，先读这份文档，再扫描 `assets/*.css`。这份文档负责回答：文章适合哪个主题、为什么适合、哪些情况不要用。

## 快速选择表

## 推荐策略

优先看内容目的，而不是只看标题。

- 要“读得久”：选 `Knowledge-Base`、`Kami`、`Academic-Paper`、`zj`、`g2`。
- 要“白皮书 / 专业观点 / 投资备忘录”：选 `Kami`。
- 要“看起来贵”：选 `Luxury-Gold`。
- 要“有情绪、有画面”：选 `Sunset-Film`、`Morandi-Forest`。
- 要“一眼抓住”：选 `Neo-Brutalism`、`Bauhaus`。
- 要“科技 / AI / 未来”：选 `Aurora-Glass`、`Cyberpunk-Neon`。
- 要“清单 / 消费 / 项目流水”：选 `Receipt`。

代码块多时，避免只追求视觉；优先保证代码可读。表格多时，优先选克制主题。图片多时，避开过强边框和硬阴影，防止画面太吵。

## 主题详解

### `Kami`

来自 `/Users/linnan/project/Kami` 的纸面文档设计系统。羊皮纸背景、单一墨蓝强调、暖灰文本层级、衬线字体和章节左侧蓝条，整体像一份克制的白皮书 / 投资备忘录。

适合：研报、白皮书、专业观点、投资备忘录、课程讲义、长篇分析。

选择关键词：羊皮纸、墨蓝、衬线、白皮书、专业、稳重、投资备忘录。

选择器依赖：`#wemd`（WeMD 主题）

### `Knowledge-Base`

干净、克制，像知识库页面。浅灰块、细分隔线、系统无衬线字体，适合结构化信息和长时间阅读。

适合：技术教程、产品说明、方法论、读书笔记、内部 Wiki、课程资料。

选择关键词：清楚、可信、结构化、工具感、Notion 感。

选择器依赖：`#wemd`（WeMD 主题）

### `Academic-Paper`

黑白为主，Times + 宋体混合字体，标题像论文分节，强调正式、严谨、可引用。

适合：研报、论文、学术摘要、课程讲义、研究笔记、严肃商业分析。

选择关键词：正式、严肃、学术、低装饰、可打印。

选择器依赖：`#wemd`（WeMD 主题）

### `Sunset-Film`

陶土红、咖啡色、衬线体和电影片名式标题，阅读感像旧信或复古影评。

适合：人物故事、访谈、复盘、旅行、生活随笔、带情绪的长文。

选择关键词：温暖、复古、叙事、电影感、回忆。

选择器依赖：`#wemd`（WeMD 主题）

### `Morandi-Forest`

莫兰迪绿色系，节奏舒缓，留白较多，有自然、安静、柔和的气质。

适合：成长、心理、读书、生活方式、慢节奏思考、长期主义主题。

选择关键词：温柔、自然、安静、疗愈、克制。

选择器依赖：`#wemd`（WeMD 主题）

### `Luxury-Gold`

宋体 / 衬线体、居中标题、金色细线和大留白，有杂志和精品品牌感。

适合：品牌故事、审美文章、艺术评论、人文商业、精品消费内容。

选择关键词：高级、精致、留白、品牌、人文。

选择器依赖：`#wemd`（WeMD 主题）

### `Receipt`

等宽字体、虚线、黑白反差，模拟小票 / 打印纸。它适合”记录”和”明细”，不适合宏大叙事。

适合：清单、账单、消费记录、项目日志、复盘备忘、极简说明。

选择关键词：小票、清单、流水账、记录、黑白。

选择器依赖：`#wemd`（WeMD 主题）

### `Bauhaus`

红、黄、蓝几何块和硬阴影，现代设计感强，标题冲击力明显。

适合：设计观点、产品发布、创意方法、短篇观点、视觉实验内容。

选择关键词：几何、设计、现代、醒目、硬朗。

选择器依赖：`#wemd`（WeMD 主题）

### `Neo-Brutalism`

粗黑边框、荧光黄、电光紫、高对比硬阴影，很适合表达态度和制造传播冲击。

适合：社媒长图文、活动说明、反常识观点、年轻化品牌、强立场文章。

选择关键词：年轻、粗粝、高对比、反叛、强传播。

选择器依赖：`#wemd`（WeMD 主题）

### `Aurora-Glass`

蓝紫粉渐变、圆角、轻玻璃感，偏明亮科技和产品体验。

适合：AI 科普、产品体验、未来生活、创意展示、轻科技文章。

选择关键词：渐变、明亮、科技、轻盈、未来感。

选择器依赖：`#wemd`（WeMD 主题）

### `Cyberpunk-Neon`

青色、粉色、切角、暗色代码块，科技感更硬，适合技术和未来主义内容。

适合：AI、编程、加密、游戏、黑客文化、强科技观点。

选择关键词：霓虹、赛博、代码、未来、黑客。

选择器依赖：`#wemd`（WeMD 主题）

### `zj`

Typora 风格主题，衬线长文、红色强调、打印规则完整。更像本地文档 / 博客页面，不是强公众号装饰主题。

适合：个人知识库、长篇读书笔记、技术 / 学术混合文档、打印稿。

选择关键词：长文、衬线、打印、知识沉淀。

选择器依赖：`#write`（Typora 主题）

### `g2`

Typora 风格主题，中文衬线阅读感强，红色主色比 `zj` 更轻。适合长文和博客，不追求强视觉装饰。

适合：学习笔记、博客文章、技术说明、偏正式的长篇内容。

选择关键词：长文、博客、阅读、简洁、打印。

选择器依赖：`#write`（Typora 主题）

### `Template`

这是新主题模板，不用于正式转换。新增主题时可以复制它，再改变量、标题、引用、代码块、表格等区域。

选择器依赖：`#wemd` + `#write`（开发模板，两者均有）

## 增删主题时怎么维护

新增 CSS 后，必须新增一节主题说明，至少包含：

- 视觉气质。
- 适合内容。
- 不适合内容。
- 选择关键词。
- 如果它是 Typora 主题，标注依赖 `#write`；如果是 WeMD 主题，标注依赖 `#wemd`。

删除 CSS 后，删除对应说明，或明确标注“已下线，不再推荐”。如果参考文档和 `assets/` 不一致，以 `assets/` 为当前可用主题，但要立即修正文档。
