# 机械自检脚本说明

用于解释报告、集成 JSON 输出及维护脚本；普通写作无需预先加载。调用方式与退出码见 [SKILL.md](../SKILL.md)。

## 覆盖范围与复核

脚本对 31 条规则提供部分机械线索（含 S2 描述性统计）。S1、W4、C1、C2、C3、C6、R1、R3 共 8 条列为人工检查项；其余规则的语义、来源和事实也须人工判断。

- S1 由人工核对凑项、冗余与重复，三项枚举本身不构成问题。
- R1 由人工检查真实判断边界；量化稿件核对样本、市场、成本与方法限制，不以「我不确定」「会失效」等关键词证明充分。
- S2 描述句长变异系数和样本句数，不参与命中、通过判定或退出码。
- `P2_prompt_colon` 仅定位散文正文中的少量句首提示冒号，继承 P2 的体裁豁免，不判断冒号是否合法。结尾套话用 P4 定位。
- F4 的助手口吻候选收窄为「需要我帮你 / 为你 / 展开 / 继续」「以下是为你 / 为您 / 您」等。「总结一下」「如下所示」「以上就是」仅为 low 候选。
- F6 不扫描「点赞」；「好问题」「完全正确」仅为 low 候选。人物原话、正常评价和礼貌对话须按语境保留。

## 文本视图与定位

预处理屏蔽 frontmatter、围栏代码块、Markdown 块引用、行内代码、URL、图片和 HTML 标签，普通链接保留可见标签。围栏闭合符与开符同类且不能更短；未闭合围栏保护至文件末尾。

统计使用两个视图：

| 视图 | 用途 |
| --- | --- |
| 屏蔽后的可见文本 | 词表、格式、开头 / 结尾 / S3 窗口、W1 密度 |
| 散文正文（另排除标题、表格、列表） | W3 计数、句数和定位；S2、S7 句段指标 |

软换行不单独分句，空行分段；S7 连续短句不跨段累计。句内正则排除 CR/LF，避免匹配跨行或跨段。所有屏蔽等长并保留换行，报告行号与字符偏移对应原文；偏移按 Python 字符数计算。

只支持常见 Markdown。复杂嵌套、缩进代码、行内引语和被讨论的词须人工复核。块引用懒续行采用保守保护，正文应以空行分开。引用中的原话不能为了降低计数而修改。

F3 按候选 emoji 基础字符计数，不单独计算 U+FE0F 和肤色修饰符，也不计 U+2190–21FF 箭头。`❤️`、`⚠️`、`👍🏻` 各计 1 次，`A → B` 计 0 次；复合 emoji 序列未做完整字素聚合，计数仍是编辑启发式。

## 体裁设置与去重

`scripts/patterns.json` 是词表、正则、阈值和体裁配置的唯一数据源。词表正则的 `severity` 可覆盖所在规则的默认严重度，用于保留低优先语境候选。

- `skip`：豁免规则，基础 ID 同时豁免其子规则。
- `strict`：只保留可将 mid 提升为 high 的规则；密度项须先超过阈值，正常用法豁免仍生效。
- `focus`：重点复核，不自动升级，也不单独触发退出码；可包含 low、高优先项或人工检查项。

同一规则的词条与正则共用候选排序：匹配长度降序，等长时原文位置升序，再跳过已选匹配占用的字符。计数和定位选择相同的匹配，不受等长词条的配置顺序影响。例如「虽然而且」计数为 2，定位「虽然」（偏移 0）和「而且」（偏移 2）。

W2 的「对……进行」「起到了……的作用」按非贪婪量词收集候选，停在首个符合条件的「进行」「的作用」，避免把后续并列内容纳入匹配；「对……进行」的中间字符排除「对」，起点落在离「进行」最近的「对」，「相对而言我们对数据进行了」只定位「对数据进行了」；候选间仍遵循上述长度与位置排序。

「与此同时」「更重要的是」「值得注意的是」「综上所述」「由此可见」归 W3；「在某种程度上」归 W5；「赋能」「生态位」归 C9，不参与 W1 密度。W1、W3 是聚合规则，统计和定位时跳过整体落在其他词表规则已命中词条内的匹配；只共用部分字符的相邻词（如「旨在一定程度上」中的「旨在」）照常计数。例如 C8「时代背景下」、P2「深入探讨一下」、P3「尽管面临」、F5「虽然公开资料有限」等只归所属规则。所属规则被体裁豁免时不认领，W1、W3 照常计数。C7 词完全包含在已命中的 S8 句式中时，只报告完整 S8 句式；独立 C7 表达仍保留。其他规则的不同问题可能在同一段落出现，不做全局静默屏蔽。

被认领而跳过的候选不写入本规则的重叠掩码，其他部分重叠候选仍可被选中。例如人为给「虽然而且」的前两字设置认领掩码时，会选择偏移 1 的「然而」。现有词表无法触发这一具体风险；该设计观察暂不调整。

## JSON 输出

| 字段 | 含义 |
| --- | --- |
| `genre` | 当前体裁 |
| `stats.chars` | 可见文本有效字数 |
| `stats.prose_chars`、`sentences`、`paragraphs` | 散文正文的有效字数、句数、段数 |
| `analysis_scope` | 统计口径和 Markdown 支持限制 |
| `metrics` | 指标值、阈值、是否超标及严重度；S2 带 `informational: true` 和 `sample_size` |
| `manual_review` | 本体裁仍需人工检查的规则与说明；R1 不在 `metrics` 中 |
| `hits` | 规则、严重度、行号、字符偏移、匹配文本、上下文与提示 |
| `counts` | 各规则候选定位数 |
| `severity_totals` | high / mid / low 待复核项总数；W1、W3 按超标指标各计 1 项，定位可有多处 |
| `strict`、`focus` | 自动加严规则与仅提示重点复核的规则 |

`counts` 用于查看定位，`severity_totals` 用于汇总和退出码，两者不一定相等。无命中不证明事实正确或出自人类；合理命中可以保留。
