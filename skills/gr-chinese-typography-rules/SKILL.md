# 中文排版规则

本规则适用于简体中文语境。写作时按以下规则产出文本。

---

## 一、空格规则

### 1.1 必须加空格

**中文与英文之间加空格。**

- 正确：在 LeanCloud 上，数据存储围绕 `AVObject` 进行。
- 错误：在LeanCloud上，数据存储围绕`AVObject`进行。

**中文与阿拉伯数字之间加空格。**

- 正确：今天买菜花了 5000 元。
- 错误：今天买菜花了5000元。

**并列含义相对的中文字符之间，使用半角 `/` 且前后加空格。**

- 正确：登录 / 注销、读 / 写、输入 / 输出
- 例外：前后已经是专有名词（自带空格）或全角标点时不加。

### 1.2 数字与单位（有弹性）

**通用规则：数字与单位之间建议加空格。**

- 推荐：宽带有 10 Gbps，SSD 有 20 TB。

**高频单位例外：** `MB / GB / TB / KB / Hz / MHz / GHz` 等技术单位，按平台惯例可不加空格（Apple 中文官网、大部分科技媒体不加）。

- 可接受：SSD 有 20TB、主频 3.2GHz。

写公众号、小红书、正式研报时倾向加空格；写技术文、日常表达时可不加。**重要：同一篇文章内保持一致，不要一会儿加一会儿不加。**

### 1.3 不加空格

**数字与度（°）、百分比（%）之间不加空格。**

- 正确：今天 33° 高温；性能提升 15%。
- 错误：今天 33 ° 高温；性能提升 15 %。

**全角标点与其他字符之间不加空格。**

- 正确：刚买了一部 iPhone，好开心！
- 错误：刚买了一部 iPhone ，好开心 ！

**Markdown 格式标记与中文之间不加空格。**（加粗、斜体、行内代码的标记算格式，不算英文）

- 正确：这是**重点**内容；执行 `pip install` 即可。
- 错误：这是 **重点** 内容。

**书名号、引号、括号的内侧不加空格。**

- 正确：在《Thinking, Fast and Slow》中；「Stay hungry」
- 错误：在《 Thinking, Fast and Slow 》中；「 Stay hungry 」

### 1.4 专有名词例外

官方写法自带特殊格式的专有名词按官方原样，不强制加空格。例如"豆瓣FM"。`iOS`、`macOS`、`iPhone` 这类本身就是专有名词，前后与中文接壤时仍需按 1.1 加空格。

## 二、全角与半角规则

### 2.1 中文语境默认使用全角标点

全角标点：`，`、`。`、`；`、`：`、`！`、`？`、`、`、`（）`、`【】`、`《》`、`「」`、`『』`、`——`、`……`

- 正确：嗨！你知道嘛？今天前台说「喵」了哎！
- 错误：嗨! 你知道嘛? 今天前台说 "喵" 了哎!

### 2.2 完整英文句、英文书名、英文专有名词内部使用半角标点

当引用完整英文句子或英文书名时，该内容内部的标点保持半角。

- 正确：乔布斯说「Stay hungry, stay foolish.」
- 正确：推荐《Hackers & Painters: Big Ideas from the Computer Age》。
- 错误：乔布斯说「Stay hungry，stay foolish。」
- 错误：推荐《Hackers＆Painters：Big Ideas from the Computer Age》。

### 2.3 数字使用半角

- 正确：这件蛋糕卖 1000 元。
- 错误：这件蛋糕卖 １０００ 元。
- 例外：设计稿、海报中为对齐可用全角数字。

### 2.4 省略号与破折号

- 省略号用 `……`（U+2026 连用两次），不用 `。。。`、`...`、`…`（单个）。
  - 例外：完整英文句内部保留英文省略号 `...`（见 2.2）。
- 省略号不与"等"连用。正确：香蕉、苹果、梨等各色水果／各色水果，有香蕉、苹果、梨……；错误：香蕉、苹果、梨……等。
- 破折号用 `——`（两个全角字符 U+2014），不用 `--`、`-` 或单个 `—`。

### 2.5 中文引号（重要，最易出错）

简体中文优先使用直角引号，外层 `「」`（U+300C / U+300D），内层 `『』`（U+300E / U+300F）。

- **推荐（直角引号）：**「老师，『有条不紊』的『紊』是什么意思？」
- **可接受（全角弯引号）：**外层 U+201C / U+201D（`"..."`），内层 U+2018 / U+2019（`'...'`），传统用法。
- **禁止（英文直引号）：**U+0022（`"..."`）和 U+0027（`'...'`）在中文正文中禁用。
  - 检查信号：如果你输出的引号在代码编辑器里显示为笔直的竖线、左右完全对称、不带任何向内弯折，就是错的。

### 2.6 括号规则

中文内容用全角括号 `（）`；括号内部即使全是英文，只要括号本身是全角，内部作为分隔的逗号、顿号、分号也用全角（句号除外）。

- 正确：核磁共振成像（NMRI）是什么原理？
- 错误：核磁共振成像 (NMRI) 是什么原理?

**例外：被注释对象和括号内容都是英文时，用半角括号并前置一个空格。**

- 正确：RightCapital (a fintech company) 的手机应用（App）于近日发布。

**句末括号加注时，句号在括号之外。**

- 正确：详见第 1.3 节（第 26 页）。
- 错误：详见第 1.3 节（第 26 页。）

## 三、标点符号规则

### 3.1 顿号用于并列

句子内部的并列词用全角顿号 `、` 分隔，**并列词是英文时同样用顿号**；最后一项用"和"或"以及"连接。

- 正确：我关注的宽基指数有沪深 300、中证 500、中证 1000 和科创 50。
- 正确：常用库有 pandas、NumPy、Polars 和 DuckDB。
- 错误：常用库有 pandas, NumPy, Polars 和 DuckDB。
- 例外：整句为英文时用半角逗号。`Common libraries include pandas, NumPy, and DuckDB.`

### 3.2 不重复堆叠标点

- 正确：德国队竟然赢了巴西队！
- 正确：她竟然对你说「喵」？！
- 错误：德国队竟然赢了巴西队！！！！！
- 错误：她竟然对你说「喵」？？！！？？！！

允许 `？！` 或 `！？` 的单次并用（疑问 + 惊叹），不允许连续堆叠。

### 3.3 英文书名、句子的引用

用中文标点符号包裹外层，内部保留英文标点。见 2.2。

### 3.4 标题末尾不加点号

标题（含小红书小标题、公众号段落标题）末尾不用 `。` `，` `、` `；` `：`；标号（`？` `！` `」` `》` `……`）可以保留。

- 正确：`## 为什么夏普比率会失真？`、`## 三个常见的过拟合信号`
- 错误：`## 三个常见的过拟合信号。`

## 四、专有名词与缩写

### 4.1 专有名词使用正确大小写

按品牌官方写法。

- 正确：GitHub、iPhone、macOS、JavaScript、Microsoft、Facebook, Inc.、LeanCloud
- 错误：github、GITHUB、Github、gitHub、GitHUB

例外：网页视觉需求导致的全大写 / 全小写，HTML 中仍按标准大小写，通过 CSS `text-transform` 实现视觉效果。

### 4.2 不使用不地道的缩写

- 正确：我们需要熟悉 JavaScript、HTML5，至少理解一种框架（如 React、Vue.js、Angular 等）的前端开发者。
- 错误：我们需要熟悉 Js、h5，至少理解一种框架（如 RJS 等）的 FED。

技术性文章首次出现英文术语时，建议同时给出中文和英文，之后按习惯使用其中一种。
面向大众的文章，能用中文就用中文。

## 五、用字规范

### 5.1 "的 / 地 / 得"

- "的"修饰名词：**美丽的**花。
- "地"修饰动词：**慢慢地**走。
- "得"用于动词补语：跑**得**快。
- 建议区分"的"和"地"。"得"在固定搭配和常用补语结构中使用，其他场景可避免。

### 5.2 "他 / 她 / 它"与性别代词

- 男性用"他"，女性用"她"，非人用"它"。
- 混合性别群体用"他们"；如群体大部分为女性，建议用"她们"。
- 不要用"他"默认指代女性或未知性别；代词选择和示例描述避免性别刻板印象。
- 以当事人性别认同为准，不对跨性别者使用其指派性别。

### 5.3 人称代词

- 对读者称"你"，不用"您"（除非是正式商务场景）。
- 对自己用"我"或"我们"。

## 六、数字、日期与金融表达式

写量化研究、金融分析、数据报告时涉及数字、日期、数学符号和指标——

### 6.1 比较与关系符号

数学符号（`=`、`≠`、`<`、`>`、`≤`、`≥`、`≈`、`±`）**前后加半角空格**。

- 正确：夏普比率 > 1.5、α = 0.05、最大回撤 ≤ 8%、IC ≈ 0.06
- 错误：夏普比率>1.5、α=0.05

### 6.2 正负号、加减运算符

**正负号**（表示数值正负）与数字直接相连，不加空格。

- 正确：+2.3%、-8.5%、净值 +0.035
- 错误：+ 2.3%、- 8.5%

**加减运算符**（表示运算）前后加空格。

- 正确：收益 = 本金 × (1 + r)、alpha + beta 拆解
- 错误：收益=本金×(1+r)

### 6.3 金融术语中英文混合

首次出现建议中英双标，之后按场景选一个固定用。

- 正确：夏普比率（Sharpe Ratio）为 1.8，最大回撤（Max Drawdown）控制在 -10% 以内
- 正确（只用中文）：夏普比率 1.8，最大回撤 -10%
- 正确（只用英文）：Sharpe 1.8, MDD -10%

### 6.4 数据区间与并列

- 时间区间用半角连字符：2020-01-01 至 2024-12-31、Q1–Q3（en dash）
- 数值区间：年化收益 15%–20%（en dash，不是 `-`）、换手率 3 ~ 5 倍/年
- **区间两端都要带单位或百分号。** 正确：67%–89%、132 kg–234 kg；错误：67–89%、132–234 kg
- 多指标并列用顿号：IC、IR、胜率、盈亏比

### 6.5 单位与数值

- 金额、基点用半角：100 万、10 亿、50 bps、3.2 倍
- 百分比、度数紧贴数字（见 1.3）
- 单位符号保持前后一致：同一篇文章里统一用"万"或"w"或"K"，不要混用

### 6.6 千位分隔符

- 5 位及以上数值加千位分隔符（半角逗号）：`3,000,000` 行、实收资本 ¥1,258,000
- 4 位数值可加可不加，全文一致：`1000` 或 `1,000`
- 不加分隔符的场景：年份（`2024 年`）、编号、代码、股票代码（`600519`）

### 6.7 日期与时间

- 中文日期：`2024 年 3 月 31 日`（月、日不补零）；纯数字日期：`2024-03-31`（补零，ISO 格式）
- 不用 `2024/3/31`；年份写满 4 位，不写 `24 年 3 月`
- 时间用**半角**冒号：`9:05`、`收盘 15:00`；不用全角 `9：05`
- 交易时段这类区间：`9:30–11:30`（en dash）

### 6.8 增减与倍数表述

- "了"表增量，"到"表定量：增加**到**两倍（1 → 2）；增加**了**两倍（1 → 3）
- 降低同理：降低**到** 80%（100 → 80）；降低**了** 80%（100 → 20）
- **不用"降低 N 倍""减少 N 倍"**，改用百分比。错误：回撤减少了 3 倍；正确：回撤从 12% 降到 4%
- 涨跌用百分点还是百分比要写明：仓位从 30% 提到 40%，是提高了 10 个**百分点**，不是 10%

## 七、执行优先级（写作时按顺序自检）

写完中文段落后按以下顺序检查：

1. **中英文 / 中数字之间的空格**（最高频错误；Markdown 加粗、书名号内侧不加）
2. **全角标点是否用对**（`，。；：！？、（）`）
3. **并列词是否用顿号**（英文并列词也用 `、`，不用 `,`）
4. **引号类型**（中文用 `「」` 或弯引号 `""`，禁止英文直引号 U+0022）
5. **数字与单位空格**（按 1.2 规则，全文一致）
6. **千位分隔符 / 日期时间格式**（5 位以上加逗号；时间用半角冒号）
7. **数学符号前后空格**（`=` `>` `<` `≤` `≥` 加空格；`+ / -` 作正负号不加）
8. **区间两端是否都带单位**（`15%–20%`，不是 `15–20%`）
9. **标点堆叠**（是否有连续重复）
10. **省略号 / 破折号**（`……` 和 `——`，不用 `...` 或 `--`）
11. **标题末尾无点号**
12. **专有名词大小写**
13. **"的 / 地 / 得"、"他 / 她 / 它"、"增加了 / 增加到"使用**

## 九、不在本规范范围内

以下内容属于个人风格或设计需求，不做强制规定：

- 句子长度、被动语态、段落组织、写作语气等**表达层面**的规则（属 gr-content-ai-avoid 范围）
- 标题层级结构（几级标题、是否跳级）
- 链接与正文之间是否加空格
- 段首是否缩进
- 行末标点省略（仅数学公式行）
- 繁体中文、港澳台习惯用法（请按地区规范调整）
- 代码块、表格单元格内的排版（按代码/数据规范即可）
