# 正误速查表

只用于快速查阅。**规范定义以 `SKILL.md` 和其他 reference 为准**，本表与它们冲突时以那边为准。

| 场景 | 正确 | 错误 |
| --- | --- | --- |
| 中英文之间 | 使用 GitHub 登录 | 使用GitHub登录 |
| 中文与数字 | 花了 100 元 | 花了100元 |
| 数字与单位 | 10 GB 内存（或全文统一用 10GB） | 同篇里 10 GB 和 10GB 混用 |
| 数字与度 | 室温 25° | 室温 25 ° |
| 数字与百分比 | 增长 15% | 增长 15 % |
| 中文标点 | 你好，世界。 | 你好, 世界. |
| 英文整句引用 | 「Stay hungry, stay foolish.」 | 「Stay hungry，stay foolish。」 |
| 省略号 | 等等…… | 等等。。。 / 等等... |
| 破折号 | 这就是答案——坚持 | 这就是答案--坚持 |
| 引号 | 「紊」是什么意思？ 或 “紊”是什么意思？ | "紊" 是什么意思？（ASCII U+0022） |
| 引号一致性 | 全篇只用「」 | 「」和“”混用 |
| 括号 | LeanCloud（云服务） | LeanCloud (云服务) |
| 英文括注 | RightCapital (a fintech company) | RightCapital（a fintech company） |
| 标点堆叠 | 太棒了！ | 太棒了！！！！ |
| 并列符号 | 登录 / 注销 | 登录/注销 或 登录／注销 |
| 英文并列 | pandas、NumPy 和 DuckDB | pandas, NumPy 和 DuckDB |
| 数学比较符 | 夏普 > 1.5 | 夏普>1.5 |
| 正负号 | +2.3%、-8.5% | + 2.3%、- 8.5% |
| 数值区间 | 15%–20% | 15%-20%、15–20%、15 ~ 20% |
| 公式括号 | 收益 = 本金 × (1 + r) | 收益 = 本金 ×（1 + r） |
| Markdown 标记 | 这是**重点**内容 | 这是 **重点** 内容 |
| 大数字 | 3,000,000 行 | 3000000 行 |
| 中文日期 | 2024 年 3 月 31 日 | 2024/3/31、03 月 31 日 |
| ISO 日期 | 2024-03-31 | 2024–03–31（误用 en dash） |
| 时间 | 收盘 15:00 | 收盘 15：00 |
| 倍数增减 | 回撤从 12% 降到 4% | 回撤减少了 3 倍 |
| 标题末尾 | ## 三个过拟合信号 | ## 三个过拟合信号。 |
| 专有名词 | GitHub、iPhone、macOS | github、Github、IPhone |
